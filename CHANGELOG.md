- Added explicit track lifecycle management, persistent IDs, and histories.
- Added analytics, overlays, atomic video output, optional audio remuxing, and run manifests.
- Added detection evaluation, MOTChallenge tracking evaluation, and runtime benchmarking.
- Added deterministic tests, static analysis, CI, licensing, attribution, and technical documentation.
